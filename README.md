# Топка — сайт-витрина

## Структура для GitHub Pages

В корне репозитория должны лежать файлы:

```text
index.html
styles.css
menu-data.js
app.js
assets/
```

Картинки должны быть внутри папки `assets`, потому что в коде пути прописаны так: `assets/logo-horizontal.png`, `assets/shashlik.webp` и т.д.

## Как обновлять меню

Меню редактируется в `menu-data.js`. Можно менять название, категорию, вес, цену и описание блюда.

## Что исправлено в этой версии

- мобильная версия сделана mobile-first;
- на ширине до 519px меню всегда в одну колонку;
- на 520–979px меню в две колонки;
- на 980px+ меню в три колонки;
- карточки растягиваются по контенту, текст и цена больше не налезают;
- длинные названия аккуратно переносятся;
- кнопка наверх и нижняя кнопка меню адаптированы под телефон.
