# Топка — сайт-витрина

Структура проекта:

- `index.html` — основная страница
- `styles.css` — стили и адаптив
- `menu-data.js` — данные меню
- `app.js` — фильтры, поиск, заказ, мобильное меню, кнопка наверх
- `assets/` — логотипы, паттерны, изображения

Для публикации загрузите содержимое этой папки в корень сайта на хостинге.

Для локальной проверки откройте `preview_single_js.html` или запустите локальный сервер и откройте `index.html`.
